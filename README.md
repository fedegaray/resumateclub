# ResuMate Club - Recursos

Recursos de código y plantillas para la comunidad [ResuMate Club](https://www.resumateclub.com).

## ¿Qué es esto?

Este repositorio contiene scripts, plantillas y ejemplos prácticos para profesionales que quieren usar tecnología para trabajar mejor y más rápido.

No necesitas ser programador para usar estos recursos. Cada uno incluye instrucciones claras para que puedas copiarlo, ajustarlo a tu caso, y usarlo.

## ¿Para quién es?

Para profesionales que:

- Quieren automatizar tareas repetitivas
- Buscan soluciones prácticas, no teoría
- Prefieren copiar y adaptar antes que crear desde cero
- Valoran su tiempo y quieren resultados rápidos

## Estructura del repositorio
```
resumateclub/
│
├── excel/              → Macros, plantillas y ejemplos de Excel
│
├── programacion/       → Scripts de Python, SQL y más
│
├── ia/                 → Prompts y workflows con IA
│
└── automatizacion/     → Scripts para automatizar tareas
```

## Cómo usar los recursos

1. Navega a la carpeta del tema que te interesa
2. Cada recurso tiene su propia carpeta con un archivo README
3. Lee el README para entender qué hace y cómo configurarlo
4. Descarga, ajusta los parámetros a tu caso, y listo
