# Prompts de Contexto para IA

Plantillas para "entrenar" a ChatGPT, Claude o cualquier IA para que entienda tu trabajo específico.

## ¿Qué es un Prompt de Contexto?

Es un bloque de texto que pegas al inicio de una conversación con la IA para darle información sobre tu rol, tu industria, y cómo quieres que te ayude.

Sin contexto, la IA da respuestas genéricas.
Con contexto, la IA da respuestas útiles para TU situación.

## Cómo usarlo

1. Elige la plantilla más cercana a tu rol
2. Copia el texto
3. Reemplaza los corchetes [así] con tu información real
4. Pégalo al inicio de tus conversaciones importantes con la IA

## Plantillas disponibles

- Analista de Datos
- Ingeniero
- Contador / Finanzas
- Administrativo / Asistente
- Gerente / Líder de equipo
- Profesional de IT / Soporte
- Recursos Humanos
- Ventas / Comercial

## Consejo

Guarda tu prompt personalizado en un archivo de texto o en las notas de tu celular. Así lo tienes a mano para pegarlo rápido cuando lo necesites.
